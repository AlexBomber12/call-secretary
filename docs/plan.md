# План реализации

| Этап | Результат и проверка |
|---|---|
| 0. Основа проекта | Публичный репозиторий, цель, ТЗ, архитектура, шаблон конфигурации. Без секретов и личных данных звонящих. |
| 1. Проверка оборудования и маршрута | Определить устройство и прошивку, подтвердить голос с реальной SIM, принять/завершить звонок, получить звук в обе стороны по USB. Проверить отдельно номер звонящего и доступность исходного семейного номера после переадресации с каждого оператора. Выбрать общий номер с вопросом об адресате либо доказанную автоматическую маршрутизацию. |
| 2. Голосовой прототип | Независимо от поставки модема: диалог через микрофон/динамик, семейные профили, короткое итальянское приветствие, выбор голоса, RU/IT/EN, перебивание, лимит 10 минут, текст и резюме. Замер задержки и фактической стоимости. |
| 3. Интеграция звонков | Подключить проверенный модемный адаптер к голосовому прототипу. Проверить отбой, переключение состояний, тишину, обрыв связи и локальную фразу при сбое API. |
| 4. Telegram и надёжность | Привязка разрешённых семейных получателей, отдельные личные отчёты, постоянная очередь с адресатом, повтор доставки, восстановление после рестарта, хранение текста без автоматического удаления. Общий месячный бюджет API €50 с постоянным счётчиком и резервированием. |
| 5. Пилот на SERVER | Отдельная служба/контейнер, минимальные права к конкретному USB-устройству, автозапуск, закрытая конфигурация. Проверить семейные маршруты, личную доставку, общий голосовой канал, реальную условную переадресацию и сохранение работы SMS-шлюза. |

Этап 0 подготовлен. Реализация и запуск на SERVER ещё не выполнены. Следующий результат — доказательство пригодности голосового тракта и работающий голосовой прототип.

На первом этапе не требуются SIP-провайдер, арендуемый телефонный номер, веб-панель или подписка на конструктор телефонии. Телефонная связь зависит от тарифа оператора; облачный голос оплачивается отдельно по фактическому использованию.
