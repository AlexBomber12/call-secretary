## Проверки, которые определяют дальнейший путь

**H1 — пригодность оборудования.** Выделенный модем с реальной SIM принимает и завершает звонки, одновременно передаёт звук в обе стороны по USB, устойчиво определяется после переподключения. Зафиксированы модель, прошивка и формат аудио. Пока это не доказано, PR-10/11 не считаются принятыми для реальной телефонии. При провале H1 выбираем другой голосовой тракт до дальнейших покупок и интеграции; программный прототип остаётся полезен.

**H2 — выбор семейного адресата.** Для каждого из трёх номеров проверяем «занято» и «нет ответа», одинакового внешнего звонящего и скрытый caller ID. Если исходный адресат надёжно доступен в метаданных — включаем подтверждённые автоматические маршруты. Если нет — остаётся одна SIM с вопросом «Per chi chiama?». Отсутствие исходного номера не блокирует пилот с уточнением адресата; полностью автоматическое именное приветствие требует подтверждённого маршрута либо отдельных входящих линий.

- **После PR-14:** работающий семейный пилот на SERVER с документированной приёмкой и откатом.

## Общие условия готовности PR

Каждый PR даёт отдельный проверяемый результат, содержит подходящую проверку своего поведения и обновляет нужную документацию. CI использует синтетические данные и поддельные внешние сервисы; реальные звонки, Telegram и API проверяются отдельно там, где это указано. Неизмеренные параметры и непроведённые проверки остаются помеченными как «не проверено».

До первого платного запроса должны работать PR-05, сохранение расходов и резервирование голосового сеанса вместе с последующим резюме. До включения реального приёма телефонных звонков — закрытая конфигурация, привязки получателей и служебная фраза для работы без API. Существующий SMS-шлюз сохраняет собственный модем и управление устройством.

Пока вне MVP: веб-панель, исходящие звонки, бронирования/обещания от имени семьи, несколько параллельных голосовых каналов. Для начальной модемной схемы SIP-провайдер и арендуемый номер не требуются; операторская связь и облачный API учитываются отдельно.
