# План реализации

| Этап | Результат и проверка |
|---|---|
| 0. Основа проекта | Публичный репозиторий, цель, ТЗ, архитектура, шаблон конфигурации. Без секретов и личных данных звонящих. |
| 1. Проверка оборудования | Определить устройство и прошивку, подтвердить голос с реальной SIM, принять/завершить звонок, получить звук в обе стороны по USB и проверить caller ID после переадресации. Это условие выбора модемного адаптера. |
| 2. Голосовой прототип | Независимо от поставки модема: диалог через микрофон/динамик, выбор голоса, RU/IT/EN, перебивание, лимит 10 минут, текст и резюме. Замер задержки и фактической стоимости. |
| 3. Интеграция звонков | Подключить проверенный модемный адаптер к голосовому прототипу. Проверить отбой, переключение состояний, тишину, обрыв связи и локальную фразу при сбое API. |
| 4. Telegram и надёжность | Структурированное резюме, постоянная очередь, повтор доставки, восстановление после рестарта, очистка текста по сроку хранения и лимиты расходов. |
| 5. Пилот на SERVER | Отдельная служба/контейнер, минимальные права к конкретному USB-устройству, автозапуск, закрытая конфигурация. Проверить реальную условную переадресацию и сохранение работы SMS-шлюза. |

Этап 0 подготовлен. Реализация и запуск на SERVER ещё не выполнены. Следующий результат — доказательство пригодности голосового тракта и работающий голосовой прототип.

На первом этапе не требуются SIP-провайдер, арендуемый телефонный номер, веб-панель или подписка на конструктор телефонии. Телефонная связь зависит от тарифа оператора; облачный голос оплачивается отдельно по фактическому использованию.
