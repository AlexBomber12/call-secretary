# Цель и техническое задание

## Цель

Принимать звонки для всей семьи, когда адресат занят или не отвечает, уточнять запрос собеседника и присылать личное резюме нужному члену семьи в Telegram. Приложение работает на SERVER; SIM-модемы подключаются к нему по USB. Пилот начинается с одного выделенного устройства.

## Сценарий MVP

1. Оператор условно переадресует звонок с личного номера члена семьи на номер приёма: «занято» или «нет ответа». Переадресация настраивается отдельно от приложения.
2. Приложение выбирает профиль адресата по проверенному входящему маршруту. Приветствие на итальянском: «Pronto, sono l'assistente di [nome]. Cosa posso riferire?» — просто помощник, без слов AI и «виртуальный». Если адресат неизвестен: «Pronto, sono l'assistente. Per chi chiama?» После определения языка разговор продолжается на языке звонящего.
3. Уточняет имя, при необходимости организацию, суть запроса, срочность и номер для обратной связи. Не выдумывает неизвестное и не даёт обещаний от имени владельца.
4. После завершения присылает только выбранному адресату в Telegram: время, доступный номер, представившегося собеседника, язык, суть, срочность, обратный контакт и следующий шаг. Неизвестные и неуверенно распознанные сведения помечаются явно. Выбор адресата со слов звонящего отмечается отдельно.

## Зафиксированные требования

- Репозиторий `call-secretary` — публичный.
- Локальное приложение на Linux; естественный голос через внешний API. Аудио передаётся провайдеру для обработки, но приложение не сохраняет аудиозаписи.
- Текст и резюме сохраняются локально **без ограничения срока**, до явного удаления или изменения политики владельцем. Аудиозаписи не сохраняются.
- Начальная конфигурация — **три семейных профиля**. Каждый содержит имя, итальянское приветствие, правила секретаря, язык отчёта и личный Telegram-чат. Маршрутизация описана в [отдельном документе](family-routing.md). Личные данные профилей не публикуются.
- На одном модеме в пилоте — максимум один разговор одновременно **на всю семью**, до **10 минут**. Перед лимитом — короткое завершение разговора, затем обязательное отключение. Дополнительные одновременные разговоры требуют отдельных проверенных голосовых каналов.
- Автоопределение языка; приёмочные языки: итальянский, русский, английский. Остальные — по возможностям выбранной модели. Русский — язык отчёта по умолчанию; допускается настройка на профиль.
- Если спрашивают, секретарь честно объясняет, что он автоматический помощник; не утверждает, что он человек. Приветствие использует только слово «помощник».
- Уведомления сохраняются в очереди до доставки, повторяются с паузой и переживают перезапуск. При неоднозначном ответе Telegram возможны повторы; сообщение содержит идентификатор звонка.
- Автозапуск, восстановление соединений и понятное состояние «модем / голос / уведомления». Бюджет голосового API — **€50 за календарный месяц суммарно для семьи**, расчёт месяца по Europe/Rome. Счётчик переживает перезапуск; перед платным сеансом резервируется стоимость предельного разговора по настроенным тарифам. При исчерпании бюджета новые платные сеансы не открываются; используется локальная фраза. Расчёт приложения сверяется с биллингом провайдера; точность тарифов и конвертации валют проверяется до пилота.
- Один бот может обслуживать семейные профили через разные `chat_id`; каждый получатель сначала запускает бота. Предлагается отдельный семейный бот; окончательный выбор ещё не сделан.
- При недоступном голосовом API — короткая локальная фраза о невозможности принять сообщение и завершение звонка; при восстановлении Telegram — отчёт об ошибке.
- Существующий SMS-шлюз и другие службы SERVER продолжают работать со своим устройством и конфигурацией.

## Приёмка MVP

- Реальные сценарии «занято» и «нет ответа» достигают секретаря; ответ владельца до переадресации оставляет разговор у владельца.
- Реальный разговор проверен на каждом из трёх приёмочных языков; слышны обе стороны, секретаря можно перебить, реплики не накапливаются после перебивания.
- При исправных API/Telegram резюме приходит не позднее 60 секунд после отбоя; недоставленный отчёт переживает перезапуск.
- Для двух и более профилей одинаковый внешний звонящий и скрытый номер не смешивают адресатов. Чужое имя/приветствие не используется до определения маршрута; личный отчёт не уходит другому члену семьи. Неопределённый адресат не вызывает рассылку всем.
- Номер передаётся только если доступен; скрытый/заменённый переадресацией номер не выдаётся за установленную личность.
- Лимит 10 минут работает независимо от модели. Проверены отбой собеседника, обрыв USB и сети, недоступность API, перезапуск приложения.
- Проверены общий бюджет €50, резервирование перед сеансом, сохранение счётчика и смена месяца. Текст не удаляется автоматически из-за возраста записи.
- В файлах, журналах, очередях и репозитории отсутствуют сохранённые аудиозаписи и ключи. Локальный текст и резюме доступны только владельцу службы.

## Решения до пилота

Общий входящий номер с вопросом об адресате либо подтверждённая автоматическая маршрутизация; отдельный или существующий Telegram-бот и привязки личных чатов; голос/модель после прослушивания; точная модель, прошивка и доступность голосовой связи на SIM. В локальной конфигурации подготовлены три профиля, оператор каждого известен. Покупка и установка оборудования пока не подтверждены.
