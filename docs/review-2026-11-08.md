## Границы вывода

H1/H2, Vodafone forwarding, реальный USB-аудиоформат, качество/задержка голоса, биллинг провайдера, живая доставка и SERVER deployment остаются непроверенными. Производственный телефонный runtime ещё не включён.

Обычные ошибки закрытия аудио теперь обрабатываются, но отмена asyncio не убивает зависший нативный вызов PortAudio в потоке. Проверка отказов реального драйвера и подходящий надзор/изоляция аудиопроцесса нужны до производственной приёмки; корутинный таймаут не является доказательством аппаратного отключения.

При сверке API использованы [официальные правила Realtime interruption](https://developers.openai.com/api/docs/guides/realtime-conversations#interruption-and-truncation), [HTTPX streaming](https://www.python-httpx.org/async/#streaming-responses) и [семантика HTTPX timeout](https://www.python-httpx.org/advanced/timeouts/).
