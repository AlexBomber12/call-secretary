# Что нужно от вас

1. **Ключ OpenAI API.** Создайте ключ для этого приложения в своём API-проекте и внесите его в `OPENAI_API_KEY` закрытого файла `.env`. Перед живыми запросами у API-проекта должна быть доступна оплата. Ключ не отправляйте в чат и не вводите в команду оболочки.
2. **Отдельный Telegram-бот для семьи.** В официальном `@BotFather` выполните `/newbot`; полученный токен внесите в `TELEGRAM_BOT_TOKEN` того же `.env`. Имя бота можно сообщить в чат, токен — только в файл. После этого создадим три личных приглашения: каждый член семьи откроет своё и нажмёт Start. [Подробные шаги](telegram-setup.md).
3. **Когда придёт SIM7600E-H:** подключите его с SIM и антенной к SERVER и сообщите, что он подключён. Сначала проверим голос/USB и данные переадресации, затем настроим семейные номера. Существующий SMS-модем остаётся отдельным.

До появления модема можно проверить голос через микрофон компьютера и личные Telegram-отчёты. Для этого достаточно первых двух пунктов. Настройка ключей сама по себе не запускает приложение и не открывает микрофон.

В локальном проекте уже подготовлены три закрытых семейных профиля. Пока они отключены до подключения получателей и живой приёмки; их активацию и остальную настройку выполним после готовности ключей. Публичные примеры содержат только вымышленные профили.

Секреты `.env`, семейные имена/номера/Telegram ID и история исключены из Git. После заполнения файла достаточно написать «ключи готовы» — значения в сообщении не нужны.
