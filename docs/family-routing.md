# Семейные профили и маршрутизация

## Что настраивается на человека

Имя адресата, варианты имени для уточнения, короткое итальянское приветствие, правила разговора, язык резюме и личный Telegram-чат. Один бот может обслуживать всю семью: сообщения отправляются по `chat_id`, а не по телефонному номеру. Каждый получатель сначала открывает бота и нажимает Start. Привязку профиля разрешает владелец приложения.

Резюме получает только выбранный адресат. Семейный групповой чат не используется автоматически. Реальные имена, номера и Telegram ID находятся в закрытом `config/family.yaml`; в репозитории есть только [синтетический пример](../config/family.example.yaml).

## Как понять, кому звонили

Разделяем три значения: **кто звонит**, **на чей личный номер позвонили изначально**, **на какую SIM/линию пришёл переадресованный вызов**. Для профиля адресата нужен второй либо однозначная привязка третьего. Номер звонящего не выбирает профиль: один человек может звонить разным членам семьи.

| Вариант | Выбор профиля | Ограничение |
|---|---|---|
| Общая SIM, сеть передаёт пригодный исходный номер | По проверенному исходному номеру/данным переадресации | Нужно доказать на каждом операторе и конкретной прошивке; пока не подтверждено. |
| Общая SIM без исходного номера | Сначала «Pronto, sono l'assistente. Per chi chiama?», затем выбор из разрешённых профилей | Звонящий должен назвать адресата; это выбор со слов звонящего, а не подтверждение сетью. |
| Отдельная SIM и голосовой канал на человека | По стабильному идентификатору входящей линии | Дополнительное оборудование и SIM; число одновременных разговоров равно числу проверенных голосовых каналов. |

Для дешёвого пилота можно использовать одну SIM и уточнение адресата. Покупать дополнительные модемы до проверки передачи исходного номера не требуется. Полностью автоматическое именное приветствие на одной общей SIM обещать до испытания нельзя.

## Проверка на оборудовании

В руководстве SIM7600 `CLIP` описывает номер звонящего. `CSSN`/`CSSU` могут сообщать о переадресованном вызове; флаг переадресации сам по себе не устанавливает исходного адресата. Документация не подтверждает сквозную передачу нужного семейного номера для конкретных SIM и операторов. На пилоте проверяем реальные метаданные, а не считаем любое поле с номером исходным адресатом.

Для каждого семейного номера: один и тот же внешний звонящий, другой звонящий, скрытый номер, «занято», «нет ответа» и отсутствие метаданных. Автоматический маршрут включаем только после проверки смысла поля и устойчивого совпадения с настроенным номером. Неоднозначный маршрут сначала уточняем голосом.

Если адресат так и не выбран, текст остаётся нераспределённым. Бот не рассылает его семье и не угадывает; оператору можно отправить только уведомление о необходимости ручного разбора без содержания разговора.

## Общие ограничения

- В начальной схеме один модем обслуживает один разговор на всю семью. Второй одновременный звонок не получает второго секретаря автоматически; поведение занятости проверяется у оператора.
- Каждый разговор длится не более 10 минут. Общий голосовой/API бюджет — €50 за календарный месяц по Europe/Rome.
- Аудиозаписей нет; текст и резюме хранятся без автоматического удаления. Доступ через бота ограничен профилем получателя.
- Итальянское приветствие известно до начала диалога. По умолчанию разговор подстраивается под язык собеседника, резюме — на русском; язык отчёта можно изменить отдельно каждому.
